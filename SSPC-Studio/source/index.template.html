THE ANALYSIS

From signal to time constant.

SSPC Studio follows the baseline correction, interval grouping, peak search, and exponential model in your sspc.py.

  1. Correct the baseline. Subtract the mean of the first N raw samples, then multiply by your scale factor. The plotted unit is nA; use a scale factor appropriate to your acquisition setup.
  2. Split by light timing. Light on includes t ≥ light-on and t < light-off. Light off includes t ≥ light-off. CSV timestamps are converted to seconds before analysis.
  3. Find the starting peak. In the first 250 samples (adjustable) of each interval, find the largest absolute corrected signal. Fit from that point to the end of the interval.
  4. Fit the response. Minimize squared residuals for a positive time constant using the model below. τ is searched on a log scale; amplitude and plateau are solved at each τ.
I(t) = (a − p) exp(−(t − t₀) / τ) + p

t₀ is the detected peak time; a is the fitted signal at t₀; p is the asymptotic plateau. Half-time is τ × ln(2), measured toward the plateau. R² measures how much signal variation the model explains; it is not a confidence interval.

Changes from the script

Uses actual timestamps instead of computed row offsets, consistently labels time in seconds, constrains τ to be positive, and shifts the time origin for numerical stability. Fits can differ from the original unconstrained fit. The search extends from one-twentieth of the minimum sample spacing to 10,000 times the fit interval. A boundary result is flagged.

The chart may reduce points for display while retaining local minima and maxima. Fitting and data export use every measurement. All processing happens in this tab, with no server, analytics, or external libraries. The bundled HEBR sample comes from the test folder beside your script.
